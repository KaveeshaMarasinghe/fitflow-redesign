# Web Preview Captures

These PNG files are actual Playwright/Chromium captures of the running Expo web app at a 390 × 844 viewport. Regenerate with `npm run test:ui`.

They show the Home, AI Workout, Progress, Community, and Nutrition screens. They are **browser previews**, not Android device screenshots, installation evidence, or proof of signed builds/store submissions. Capture the actual APK on Android for the corresponding lab evidence.
